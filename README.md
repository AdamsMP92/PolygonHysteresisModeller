# PolygonHysteresisModeller

Generate synthetic hysteresis curves as polygonal chains with normalized field
and magnetization coordinates.

## Quick start

```sh
pixi run notebooks
```

The notebook contains the model description, curve plots, and six MaMMoS
analysis examples. [Open the notebook](notebooks/examples.ipynb)

[Run the notebook on Binder](https://mybinder.org/v2/gh/AdamsMP92/PolygonHysteresisModeller/main?urlpath=lab/tree/notebooks/examples.ipynb)
